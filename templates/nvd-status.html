📝 Methodology

Data Sources

  • NVD (National Vulnerability Database): Primary source for CVE data and status
  • Update Frequency: Data refreshed every 6 hours via GitHub Actions

Status Definitions

  • Analyzed: CVE has been fully analyzed by NVD
  • Awaiting Analysis: CVE is in the queue for NVD analysis
  • Modified: CVE has been updated since initial analysis
  • Received: CVE has been received but not yet processed
  • Undergoing Analysis: CVE is currently being analyzed
  • Rejected: CVE has been rejected/withdrawn

Counting Rules

  • Rejected CVEs are excluded from quarterly totals and growth calculations
  • Status counts include all CVEs regardless of rejection status
  • Projections are annualized from year-to-date data for the current year
